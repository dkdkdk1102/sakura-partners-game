# 伊豆の旅 〜うさぎと、伊東をめざして〜

サクラパートナーズ様 待合用 横スクロールゲーム（伊豆・伊東テーマ）

修善寺 → 浄蓮の滝 → 河津桜 → 下田ペリーロード → 城ヶ崎海岸 → 大室山 → **伊東温泉ゴール** の全7ステージ。
各ステージの最後には、その土地にちなんだボスが待ち受けます。

タイトル画面から **店内ランキング**（ハイスコアになまえ登録・端末内保存）、**ミニゲーム**（いとうの さかなつり／温泉まんじゅうキャッチ）も遊べます。
タイトルで30秒さわらないと自動でデモプレイが流れます（画面タッチで即復帰）。

## 🚀 もうひとつのゲーム「うさメカ パトロール」
タイトルの「🚀 シューティング」ボタン（または `shooter.html`）から、横スクロールシューティングが遊べます。
- うさぎが操縦するメカで伊豆の空をパトロール。**3ワールド×3ステージの全9ステージ**（1-1〜3-3）
- 各ワールドの途中ステージには**中ボス**（トビウオ番長／大機雷トゲ丸／ぼんぼり親方）、最後に大ボスが待ち受ける
- **難易度3種（やさしい／ノーマル／ハード）**: 弾の速さ・敵の連射・ボスの体力・敵の数が変化。ハードはスコア1.4倍
- 大ボス：おおダコ提督／とっこう隊長・大カモメ／ウニ大魔王
- そうさ：**ゆびでドラッグ**（または矢印キー）で移動、ショットは自動、**BOMBボタン**（X/Shiftキー）でボム
- 温泉マーク=パワーアップ、まんじゅう=ボム、ハート=回復。コンボでスコア倍率アップ
- シューティング専用の店内ランキングつき。右上の🐰ボタンで冒険ゲームに戻れます

## 冒険ゲームの操作（アップデートで追加）
- **二段ジャンプ**：空中でもう一度ジャンプでふんわり二段目
- 近くのみかんは吸い寄せられます／チェックポイントでハート回復／連続踏みつけでコンボボーナス
道中で「物件」を集め、各地の豆知識（事実確認済み）を読みながら、うさぎが伊東を目指します。

## いちばん簡単な起動方法（おすすめ）

1. `game` フォルダの中の **`index.html`** を **ダブルクリック**するだけ。
2. お使いのブラウザ（Chrome / Edge / Safari）で全画面表示されます。
3. 画面右上の **⛶ ボタン**で全画面（フルスクリーン）に切り替えできます。

> ネット接続は不要です。フォントも端末標準のものを使うので、オフラインの待合タブレットでもそのまま動きます。

## 操作方法

| やりたいこと | タッチ（タブレット） | キーボード（PC） |
|---|---|---|
| 移動 | 画面左下の ◀ ▶ | ← → |
| ジャンプ | 右下の大きい ⤴ | スペース / ↑ |
| ダッシュ | 右下の Ｂ | Shift |
| しゃがむ／降りる | 左下の ▼ | ↓ |
| ポーズ | 右上の ⏸ | Esc |

- 敵は **上から踏む**とやっつけられます（トゲのある敵はよけましょう）。
- **みかん**を100個集めると残機が1つ増えます。**温泉♨**でハート回復。
- 旗の**チェックポイント**を通ると、やられても途中から再開できます。
- 難易度は最初に **やさしい / ノーマル** を選べます（待合なら「やさしい」推奨）。

## タブレットでのおすすめ設定（待合運用）

- **横向き（ランドスケープ）**で使用してください。
- ブラウザを**全画面（キオスクモード）**にすると、お客様が他の画面に行きにくくなります。
  - iPad（Safari）：ホーム画面に追加 → フルスクリーンのWebアプリとして起動できます。
  - Chrome/Edge（Windowsタブレット）：`--kiosk "（index.htmlのフルパス）"` で起動。
- 画面右上の 🔊 / ♪ ボタンで効果音・BGMの ON/OFF を切り替えられます（待合では音量を絞るか、♪OFF推奨）。

## うまく表示されない場合（簡易ローカルサーバ）

ごく一部の環境（古いブラウザ等）で `index.html` の直接起動がうまくいかない場合は、
`game` フォルダで以下を実行し、表示されたURLをブラウザで開いてください。

```
# Python が入っている場合（Mac標準）
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

## 中身（メンテナンス向け）

- `index.html` … 本体（これを開くだけ）
- `assets/sprites/` … 切り出し済みスプライト画像（透過PNG）
- `data/atlas.js` … スプライト一覧、`data/facts.js` … 各名所の豆知識（出典付きで事実確認済み）
- `js/engine/` … 汎用エンジン（ループ/入力/音/描画）
- `js/game/` … ゲーム本体（プレイヤー/敵/アイテム/ステージ等）
- `js/game/levels.js` … ステージ構成（ここを編集すると面を作り替えられます）

外部ライブラリ・ネット接続・ビルド工程は一切不要です。すべて素のHTML/JS/画像のみ。
